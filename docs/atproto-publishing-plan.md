# AT Protocol publishing plan

## Decision

Use GitHub and AT Protocol together.

- GitHub is the canonical versioned record for public-safe documentation, provenance, policies, corrections, and templates.
- The protected Drive workspace holds audio, stems, sessions, contracts, and unpublished source material.
- PLYR / AT Protocol carries disclosed listening artifacts and audience response.
- Standard.site carries portable long-form project entries.
- An artist-owned website provides the professional front door.

## Record relationships

Each public audio experiment should point to:

- a stable project identifier;
- title and version;
- human authorship fields;
- AI tool and transformation fields;
- source-asset status without exposing private URLs;
- rights and release status;
- experiment question;
- correction link;
- canonical repository revision.

The repository should record the corresponding AT URI once verified.

## Publication gate

Do not publish or update an ATProto record until its disclosure, rights status, title, contributors, and version are verified. Do not describe a test artifact as a finished EP master.

## Portability

Where supported, publish the journal through Standard.site records and provide the required reciprocal verification on the eventual artist-owned domain. AT Protocol supplements the repository; it does not replace contracts, storage, or release clearance.
