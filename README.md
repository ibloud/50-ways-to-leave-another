# 50 Ways to Leave Another

A transparent, rights-aware pre-production record for a proposed five-song EP.

This repository documents how Dominique Devereaux / Loptr Lab turns a private creative archive into a commissionable music project while using ChatGPT/Codex for research, organization, economic analysis, documentation, and technical implementation.

> **Current status:** pre-production and proposed collaboration. Charlie J is not represented as an attached artist, endorser, or rights participant unless and until he accepts an agreement and approves named public participation.

## What lives here

- the creative and delivery brief;
- project status and approval gates;
- AI-use and authorship disclosures;
- provenance and rights controls;
- public-source platform economics;
- a proposed collaborator offer;
- the PLYR/Suno listening-test protocol;
- the GitHub + Drive + AT Protocol publishing architecture;
- reusable contribution, split-sheet, rights-envelope, and delivery templates.

## What does not live here

No masters, stems, sessions, private messages, contracts, personal data, access-controlled Drive links, or unpublished collaborator work are committed to this repository.

## Architecture

| Layer | Role |
| --- | --- |
| GitHub | Canonical public-safe decisions, revisions, provenance, and policy |
| Protected Drive workspace | Source audio, stems, sessions, contracts, and working materials |
| PLYR / AT Protocol | Public listening, portable identity, and disclosed audience-response experiments |
| Standard.site | Portable long-form project journal and case studies |
| Artist-owned website | Portfolio, EPK, services, inquiry, and professional identity |

## Core principle

ChatGPT is not the artist. It helps artists inspect fees, clarify rights, define complete scopes, preserve decisions, and build infrastructure they control. Human contributors retain authorship, consent, credit, and final creative judgment.
