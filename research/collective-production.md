## Practice: one idea, three expressions

**Task:** use an existing approved original project idea to prepare a short music description, a three-panel storyboard and a text-only wearable-design brief. Use existing tools and approved assets; no additional cash spend.

1. Name the project and the approved source material. Record its version and where it belongs.
2. Describe the shared idea in one sentence, then explain what each medium contributes.
3. Record the contributor role, credit preference, permission evidence and unresolved questions for each expression. Agree scope before asking another person to work.
4. List production needs and unknown costs. Keep mockups separate from manufacturable products and a quote separate from an approved order.
5. Save the result in the project's existing working record. Share only approved public details through its existing GitHub checkpoint path.

**Copyable worksheet:**

```text
Project / approved source version:
Shared idea:
Music description:
Three storyboard panels:
Wearable-design brief:
Contributor roles / chosen credits:
Asset permission evidence / unresolved uses:
Production needs / unknown costs:
Access needs / remote alternative:
Next bounded action / reviewer:
```

**Fictional worked example:** an unnamed fictional collective explores finding a way home. Its music description specifies a repeating original rhythmic motif; its storyboard moves from a closed door to an illuminated path; its wearable brief uses an original path drawing. One creator prepares all three drafts using existing tools. No audio recording, finished garment, paid commission or public launch is implied. Production prices and audience demand remain unknown; the next action is a private coherence review, not an order.

**Done means:** all three drafts express the same idea; source versions, roles, chosen credits and unknowns are explicit; no borrowed collective branding or unsupported ownership claim appears; the next action fits the approved budget. A reviewer can explain the connection without guessing. This is a learning result, not legal clearance or commercial validation.
