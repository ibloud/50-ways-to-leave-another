# Accessibility standard

The package must remain usable without video, expensive software, high bandwidth, or a desktop computer.

Required: semantic headings, meaningful links, keyboard navigation, visible focus, contrast, responsive layouts, captions for speech, instructional transcripts, meaningful media descriptions, downloadable Markdown or printable equivalents, plain-language summaries, glossary links, labeled forms, no forced public disclosure, third-party-media warnings, and testing on mobile/tablet, keyboard-only navigation, zoom, reduced motion, and a screen reader.

Music cannot be fully translated into text, but its instructional purpose, structure, authorized lyrics, and relevant listening observations should be described. Publish an accessibility contact and remediation process before calling the package complete.
