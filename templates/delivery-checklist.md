# Delivery checklist

## Audio

- [ ] Final master, 24-bit / 48 kHz WAV or agreed specification
- [ ] Clean version
- [ ] Instrumental
- [ ] A cappella
- [ ] Performance track
- [ ] Consolidated stems aligned from the same start time
- [ ] Agreed editable sessions
- [ ] Reference MP3

## Documentation

- [ ] Final lyric sheet
- [ ] Credits
- [ ] Split sheet
- [ ] Contribution records
- [ ] Rights envelopes
- [ ] Sample, beat, and interpolation disclosures
- [ ] AI-use disclosure
- [ ] BPM and key
- [ ] Explicit-content status
- [ ] ISRC-ready metadata
- [ ] Plug-in and software list where sessions are delivered

## Acceptance

- [ ] Technical defects corrected
- [ ] Revision allowance reconciled
- [ ] Track approval recorded
- [ ] Final payment condition met
- [ ] Master and publishing terms effective
- [ ] Release clearance approved


## AI-assisted release practice

- [ ] Attach the [capstone comparison and evidence record](../exercises/fictional-capstone.md#ai-assisted-release-decision) to the rights envelope.
- [ ] Record musical fit separately from proceed, hold, or choose another option.
- [ ] Keep any held candidate out of the approved release package until the named permission evidence is supplied and reviewed.

## Promotional references and disclosures

- [ ] For each campaign asset, distinguish a source link/embed, lyric quotation/adaptation, recording, product photograph and character reference.
- [ ] Record the source, date, proposed use, applicable terms/law, permission evidence and unresolved holds; “demo only” is not clearance.
- [ ] Describe actual AI assistance, source-video loading and rights limits accurately; keep purchases optional.
- [ ] Review the [worked campaign example](../exercises/fictional-capstone.md#promotional-campaign-example-a-story-reference-is-not-lyric-clearance). Do not copy its disclosure if it does not match your build.
