# Delivery checklist

## Audio

- [ ] Final master, 24-bit / 48 kHz WAV or agreed specification
- [ ] Clean version
- [ ] Instrumental
- [ ] A cappella
- [ ] Performance track
- [ ] Consolidated stems aligned from the same start time
- [ ] Agreed editable sessions
- [ ] Reference MP3

## Documentation

- [ ] Final lyric sheet
- [ ] Credits
- [ ] Split sheet
- [ ] Contribution records
- [ ] Rights envelopes
- [ ] Sample, beat, and interpolation disclosures
- [ ] AI-use disclosure
- [ ] BPM and key
- [ ] Explicit-content status
- [ ] ISRC-ready metadata
- [ ] Plug-in and software list where sessions are delivered

## Acceptance

- [ ] Technical defects corrected
- [ ] Revision allowance reconciled
- [ ] Track approval recorded
- [ ] Final payment condition met
- [ ] Master and publishing terms effective
- [ ] Release clearance approved


## AI-assisted release practice

- [ ] Attach the [capstone comparison and evidence record](../exercises/fictional-capstone.md#ai-assisted-release-decision) to the rights envelope.
- [ ] Record musical fit separately from proceed, hold, or choose another option.
- [ ] Keep any held candidate out of the approved release package until the named permission evidence is supplied and reviewed.
