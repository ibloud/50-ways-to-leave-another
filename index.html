What this site actually does

It documents the path from a private creative archive toward a commissionable music project: creative scope, contributor protections, AI-use disclosure, provenance, rights questions, platform research, and approval gates.

GitHub contains only public-safe project documentation. Source audio, sessions, contracts, receipts, private messages, personal data, and unpublished collaborator work belong in protected storage and are not published here.
